Sound files go here. Vite copies `public/` to the bundle verbatim, so a file
dropped in this directory is served at `/games/capone/audio/<name>`.

What to get and where to get it: **../../ASSETS.md**.
Which file is which noise: **src/audio/bank.ts**.

Every file committed here needs a row in ASSETS.md §6 recording its source and
licence. A file whose licence cannot be established does not belong in the repo.
